## Procedimentos específicos de uma aplicação

Quando um procedimento vale apenas para uma aplicação, ele pertence à documentação daquela aplicação, em `docs/apps/<aplicacao>/`. Os guias desta pasta são transversais: valem para o projeto como um todo.
